# Architecture

Architecture decisions and diagrams for the reusable FreeCAD Engineering Toolkit.

- [Design-Led Engineering](design-led-engineering.md) — foundational principle, proposed for review.
- `diagrams/` — source-controlled diagrams, preferably Mermaid (`.mmd`).

Review architecture changes in pull requests before merging. Keep project-specific engineering records and generated CAD artifacts outside this source repository.
